# 📇 Vault Electrónico de Contactos

Aplicación web para administrar una agenda personal de contactos.

## 🛠️ Tecnologías utilizadas

- ASP.NET Core 10
- C#
- Entity Framework Core
- SQLite
- Docker
- Docker Compose
- Git
- GitHub

## 📋 Funcionalidades

La aplicación permite:

- Registrar contactos.
- Listar contactos.
- Consultar el detalle de un contacto.
- Editar contactos.
- Eliminar contactos.
- Buscar contactos por nombre o apellido.

Cada contacto contiene:

- Nombre.
- Apellido.
- Teléfono.
- Correo electrónico.
- Empresa.
